# Atribusi Gambar Knowledge Demo

Semua asset berikut adalah ilustrasi SVG orisinal yang dibuat khusus untuk
repository SIPAKARBUN. Tidak ada gambar eksternal atau hotlink runtime yang
digunakan, sehingga asset dapat direproduksi setelah `git clone`.

| File | Subject | Author/source | License |
|---|---|---|---|
| `karat-daun-kopi.svg` (penyakit/gejala) | Daun dengan bercak jingga | SIPAKARBUN demo asset, dibuat untuk repository ini | Original internal asset |
| `busuk-buah-kakao.svg` (penyakit/gejala) | Buah kakao dengan area busuk | SIPAKARBUN demo asset, dibuat untuk repository ini | Original internal asset |
| `bpkc-cengkeh.svg` (penyakit/gejala) | Cabang cengkeh dengan gejala | SIPAKARBUN demo asset, dibuat untuk repository ini | Original internal asset |
| `busuk-pucuk-kelapa.svg` (penyakit/gejala) | Pucuk kelapa | SIPAKARBUN demo asset, dibuat untuk repository ini | Original internal asset |

Sumber fakta penyakit tidak berarti sumber gambar. Ilustrasi ini hanya untuk
validasi rendering dan alur Knowledge; jangan dipakai sebagai bukti diagnosis
visual lapangan.
